# JSP-000690-Lean — Erdős Problem #834

**Independent Lean 4 formalization** of a complete solution to

> **Justin Sun Prize JSP-000690** (= Erdős problem **#834**)
> *"Is there a three-uniform, three-chromatic-critical hypergraph with minimum degree at least seven?"*

Answer: **yes** — and this repository contains an explicit 9-vertex witness together with a
kernel-checked certificate of every property.

---

## What is claimed here

**Lean formalization contribution only.**

- The *mathematical* result that such a hypergraph exists is due to **Li [Li25]**, as recorded on
  [erdosproblems.com/834](https://www.erdosproblems.com/834). We claim **no** part of the
  mathematical discovery.
- What this repository contributes is an **independently produced Lean 4 formalization**:
  the witness hypergraph was re-derived from scratch by a SAT search written for this project
  (`tools/find_e834_sat.py`), **not** copied from any pre-existing Lean source, and the
  verification is a self-contained Mathlib file.

## The witness

A 3-uniform hypergraph on the 9 vertices `Fin 9` with **22 edges**, minimum degree **7**
(degrees `7,7,7,10,7,7,7,7,7`).

Certified in `Main.lean`:

| theorem | statement |
| --- | --- |
| `H834_uniform` | every edge has exactly 3 vertices |
| `H834_mindeg`  | every vertex lies in at least 7 edges |
| `H834_chi3`    | the hypergraph is **not** 2-colourable (chromatic number ≥ 3) |
| `H834_vertex_critical` | deleting **any vertex** makes it 2-colourable |
| `H834_edge_critical`   | deleting **any edge** makes it 2-colourable |
| `erdos_834_exists`     | hence a 3-critical 3-uniform hypergraph of minimum degree ≥ 7 exists |

Every one of these is closed by `by decide`, i.e. by exhaustive kernel computation — there is
no `sorry`, no `admit`, and no new axiom.

```
#print axioms Erdos834.erdos_834_exists
-- [propext, Classical.choice, Quot.sound]
```

## Conventions

The source problem leaves two conventions implicit; they are fixed here explicitly
(see `STATEMENT.md`):

- **Deleting a vertex `v`** — pass to the induced sub-hypergraph on the remaining vertices,
  i.e. keep exactly the edges that do not contain `v`. (This is the convention that keeps the
  hypergraph 3-uniform.)
- **Deleting an edge `e`** — erase `e` from the edge set; the vertex set is unchanged.
- **Chromatic number 2** — there is a 2-colouring of the vertices with no monochromatic edge.
